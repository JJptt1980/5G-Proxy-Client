# 狀態（GW fork）

## 目前進度
- 分支 `gw`（從上游 987f28a 開出）：伺服器位址填 `gateway`/`auto` 時自動用 Wi-Fi 預設閘道 IPv4；預設值改為 `gateway`。
- debug 版套件名稱加 `.gw`、App 名稱「5G Proxy Client GW」，可與原版並存。
- 主畫面改版（MainActivity.buildUi／updateStatus）：最上面是狀態卡（灰＝未連線、黃＝連線中、綠＝已連線並顯示實際 IP、紅＝錯誤），下面是大的藍色啟動／紅色停止按鈕；伺服器、隧道模式用分組卡片；DNS、認證、其他、設定檔收進「進階設定」，預設收起，展開狀態存在偏好設定 ui_advanced_expanded。
- TunSocksService 新增 currentServerIp，給狀態卡顯示實際連到的 IP。
- 已確認 `./gradlew assembleDebug`（JDK 17）可編譯。
- 自動重連改成固定 3 秒（原本 10s→20s→…→300s 遞增）；修正重連成功後狀態卡停在「N 秒後自動重連」不變綠的問題（原專案就有的 bug）。實機停 Pro 再開確認：每 3 秒重連，Pro 回來後自動變回「隧道已啟用」。
- 自動判別有沒有 Pro（2026-11-23）：開隧道前先對 gateway:埠做 SOCKS5 打招呼，Pro 不在就不開隧道（網路照常走 Wi-Fi），服務與通知留著「等待 Pro」，每 10 秒＋換 Wi-Fi 時檢查，Pro 出現自動接上；運作中 Pro 不見（看門狗重連前探測失敗，或連續 2 次定時探測失敗）就關隧道回到等待。按停止才完全結束。V2126 連家裡 Wi-Fi 實測：顯示「等待 Pro」、沒有 VPN、網路正常。2026-11-24 V2126 在 X200 Pro 熱點上實測：Pro 停掉時 15:26:51 自動關隧道回到「等待 Pro」，Pro 再啟動時 15:35:50 自動接上。
- 首頁固定一頁（2026-11-23，/ui 12 點全做）：鎖直式；拿掉標題列；狀態卡 → 連線摘要卡（Pro 手機位址＝實際閘道 IP:埠、模式一句話，點一下開「連線設定」）→ [連線設定][進階設定] → 主按鈕在最下面（按下微縮＋震動）。連線設定、進階設定改成從下往上滑出的面板。連不上時狀態卡寫出實際連的 IP 並問「是不是沒連到 Pro 手機的熱點？」＋「Wi-Fi 設定 ›」。模式改一排三格切換鈕；「選擇 App（已選 N 個）」只在非全部模式出現；術語改白話；設定檔的儲存／刪除／匯出／匯入收進「⋯」選單；拿掉 emoji。V2126 實機截圖確認首頁與兩個面板。
- 2026-11-21 實機驗證成功（vivo V2126 連手機熱點、手機跑 5G Proxy Pro）：gateway 自動抓到閘道、狀態卡顯示綠色「已連線」。

- 摘要卡顯示這台 IP（2026-11-24）：「自動用 Wi-Fi 閘道 · 這台 10.63.154.76」，方便跟 Pro 的「誰在用」對照。V2126 實機確認。

- 跟 Pro 報名（2026-11-24）：探測 Pro 時，不用認證就順便 CONNECT「<8碼ID>.<名字hex>.gw-id.invalid」，ID 第一次用時亂數產生後固定，名字取系統裝置名稱（沒有就型號），讓 Pro GW 的「誰在用」認得這台；原版 Pro 只會當連線失敗，不影響探測結果。單元測試通過。V2126＋X200 Pro 實測：ID ea86c8dc 被 Pro 認出，清單顯示原本取的名字。
